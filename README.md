# Aura Codex

Universal engineering foundation for the Aura Ecosystem.

### Purpose

Aura Codex provides reusable engineering rules, CI workflows, security standards, documentation conventions, and automation scripts for Aura repositories.

## Principles

- Production-ready
- Modular
- Secure by default
- AI-native
- Web4-ready
- Blockchain-ready
- Developer-first
- Continuously maintained

## Validation

Never report a build, test, security scan, or deployment as successful unless it has actually been executed and verified.
